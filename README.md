# FreeWorks Dashboard

Panel de control web para la gestión de proyectos de trabajadores freelance.

## Descripción

FreeWorks Dashboard es un MVP desarrollado con Angular y Django. Permite administrar proyectos, entregables, avances, comentarios de clientes, filtros, notificaciones y estadísticas visuales.

## Tecnologías

- Angular
- TypeScript
- Django
- Django REST Framework
- SQLite
- Docker
- Git y GitHub
